## 열기

1. 압축을 풀고 Godot 프로젝트 관리자에서 project.godot를 가져온다.
2. F6 또는 F5로 main.tscn을 실행한다.
3. Near/Far로 카메라 거리, Orbit으로 자동 회전을 조절한다.
4. Auto LOD/LOD0/LOD1 버튼으로 전환 차이를 비교한다.

주황색 캡슐 캐릭터를 방향키 또는 Move -X/+X/-Z/+Z 버튼으로 이동한다.
이동은 월드 축 기준이며 카메라 회전에 따라 방향이 바뀌지 않는다.
Reset walker로 통로 시작점에 복귀한다. 이동 속도는 2.5m/s다.
캐릭터 반경 0.25m, 높이 1.6m, 중력 9.8m/s², floor snap 0.15m를 사용한다.
버튼은 터치 가능 크기로 만들었지만 모바일 기기 실측은 미완료다.
20개 오브젝트와 실제 지면, 조명을 생성한다. 7개 원본 GLB와 4개 LOD1 GLB를 포함한다.
모델은 GLTFDocument로 로딩하고 PackedScene 캐시로 재사용한다.
파일 로딩 실패는 오류로 기록하며 자체 검사에서 실패로 처리한다.

## LOD 동작

0.1초마다 모델 높이의 화면 투영 길이를 계산한다.
80px 미만에서 LOD1, 100px 초과에서 LOD0으로 복귀한다.
중간 구간은 이전 상태를 유지한다. Near plane에 걸치면 LOD0을 유지한다.
LOD1이 없는 울타리와 끝 기둥은 항상 LOD0이다.
양쪽 시각 노드를 유지하며 visibility로 바꾸므로 GPU/메모리 절감량이
삼각형 감소율과 같다고 볼 수 없다. 크로스페이드는 아직 없다.
화면에 표시하는 triangles는 선택된 에셋의 합계이며 뷰 절두체, 그림자,
지면·UI 등을 포함한 GPU 전체 렌더 수치가 아니다.
FPS는 실행 중 측정값이며 이번 작업에서 측정한 벤치마크 결과가 아니다.

## 충돌체

20개 배치에 정적 충돌체 34개와 지면 박스 1개를 생성한다.
캐릭터에는 별도로 캡슐 충돌체 1개가 있다. HUD의 shapes 35는 환경 개수다.
원본 Z-up 명세를 Godot Y-up으로 변환한다. 양의 Z yaw는 양의 Y 회전이다.
바위=ConvexPolygonShape3D, 나무=CylinderShape3D, 울타리=BoxShape3D.
시각 LOD 변경 시 물리 노드와 충돌체는 유지한다.
환경 collision layer는 1, mask는 0이다. 프로젝트 통합 시 플레이어 mask에
환경 레이어를 포함해야 한다. 나무의 잎과 가지는 충돌에서 제외한다.

- 100/500/1000개 환경물 배치로 기기별 프레임 시간과 메모리 측정.

실행 파일 내보내기 preset은 포함하지 않았다. 내보내려면 런타임 로딩하는
GLB와 JSON 원본이 패키지에 포함되도록 export 필터 및 원본 파일 유지 설정을
해당 Godot 버전에서 확인해야 한다. 현재 제공 범위는 에디터용 소스 프로젝트다.

## 렌더 검증 제한

가상 화면용 Xvfb 설치를 시도했으나 시스템 사용자/그룹 전환 권한 제한으로 실패했다.
해당 제한을 변경하지 않았다. v0.8에는 실제 렌더 캡처가 없으며 reference/ 이미지는
이전에 생성한 기하학적 미리보기다. 헤드리스 물리 검사 결과를 렌더 품질·모바일
프레임 성능의 증거로 사용하지 않는다.
