# Trailwood 통나무 품질 개선 초안

2026-10-28. 검토용이며 기존 배포 모델 미교체.

균일한 원통을 불규칙한 10각 단면과 중간이 굵은 3단 구조로 변경했다. 양쪽 절단면을 서로 다른 각도로 기울이고, 절단면과 같은 평면 안에 큰 나이테 띠를 구성했다. 수피는 두 명도, 단면은 두 색으로 구분한다. 외부 모델 입력 없는 자체 절차 생성 형상이다.

- `resource_wood_quality.glb`: 160삼각형(기존116), 4재질, Y-up·미터, 바닥 높이0, 정면 -Z. 통나무 길이는 X축.
- JSON/Python: 부품 데이터와 생성 소스. Blender 원본 미제공.
- `comparison.png`: 동일 카메라·스케일·광원 아래 전후 비교. 폴리곤 증가는 품질 점수가 아니다.
- `six_views.png`, `wood_64.png`, `wood_128.png`, `wood_256.png`: 방향별/작은 화면 확인용.

Python 3, NumPy, SciPy, Pillow 설치 후 `python build.py`, `python check.py`, `python render_review.py` 순서로 재현한다.

유한 좌표, 퇴화면 없음, 용접 좌표 기준 몸체/가지의 닫힌 에지와 방향, 양의 체적, 바닥 높이, GLB 헤더/재질/삼각형 수 검사를 통과했다. 별도 Three.js GLTFLoader로 로드·160삼각형·4재질·재질 값·바닥 경계를 확인했다.

가지와 몸체는 별도 부품이며 의도적으로 겹친다. 전체를 단일 수밀 메시로 합치지 않았다. 나이테는 작은 화면용으로 단순화했으며 실제 나무 단면의 불규칙성을 충분히 재현한 최종 미술본은 아니다. 간이 검토 렌더는 엔진 PBR/그림자를 재현하지 않는다. Unity/Godot, 실기기 GPU, glTF 공식 검증, 사용자 식별성과 판매 미술 승인은 남아 있다.
