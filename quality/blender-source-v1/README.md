# Trailwood 6종 — Blender 편집 원본 검토본

2026-10-28. **Blender 4.5.9 LTS에서 생성·재열기 검증한 편집 원본이다. 판매 품질 승인은 아직 보류하며 기존 게임 GLB는 교체하지 않았다.**

## 제공 내용

- `blend/`: 상자·광석·코인·밧줄·포션·통나무의 개별 `.blend` 파일.
- `inputs/`: 자체 제작한 미술 2차 검토본의 부품별 원본 JSON.
- `build_blends.py`: JSON에서 Blender 원본과 Cycles CPU 렌더를 만드는 스크립트.
- `check_blends.py`: 원본을 실제로 다시 열어 검사하는 스크립트.
- `renders/`: 같은 조명과 AgX 설정의 개별 렌더 및 통합 비교판. 상자는 열린 상태도 포함.
- `reports/`: Blender 빌드 환경, 생성 결과, 재열기 검사 결과.

외부 모델이나 텍스처를 포함하지 않는다. Blender 실행 파일은 재배포하지 않는다. 다운로드 파일의 SHA-256을 공식 배포 체크섬과 비교한 기록은 environment.json에 있다.

## 편집 구조

`EditableAsset` 컬렉션 아래 자산 루트와 이름이 있는 부품을 배치했다. 재질은 색상/표면 프로필별 Principled BSDF이며 Base Color·Metallic·Roughness를 직접 변경할 수 있다. 텍스처와 외부 파일 의존성은 없다.

상자는 42개 메시 부품과 `LidHinge`를 가진다. 뚜껑 부품은 경첩의 자식이다. `Chest_Open` 액션은 30fps에서 프레임1=0°, 프레임10=52.5°, 프레임19=105°로 선형 회전한다. 18프레임 간격이므로 열림 구간은 0.6초다. 파일은 닫힌 상태로 저장했다.

Blender의 좌표는 Z-up·미터다. 원본의 Y-up 좌표를 (x,-z,y)로 변환했으며 원본 정면 -Z는 Blender +Y다. 메시 오브젝트의 스케일은1이고, 상자 뚜껑만 경첩 로컬 좌표를 사용한다.

상자와 광석에 `Optional_edge_finish` Bevel 모디파이어를 넣었지만 **뷰포트/렌더 모두 꺼져 있다**. 얇은 금속판과 맞닿는 부위에 대한 검토 없이 전체에 켜지 않는다. 기본 메시와 제공 렌더는 기존 조형을 유지한다.

이 파일은 부품 단위로 편집할 수 있는 삼각형 메시 원본이다. 수작업 쿼드 리토폴로지나 스컬프팅 원본이라는 뜻은 아니다. Blender에서 직접 GLB로 내보내면 부품·재질·정점 배치가 기존 압축 GLB와 달라질 수 있다. 동일한 게임 제공본을 재현하는 경로는 `../core6-r2/`와 `../core6-r3/`의 생성기다.

재현 명령(저장 폴더를 절대 경로로 지정):

```
blender --background --python build_blends.py -- /absolute/path/to/blender-source-v1
blender --background --python check_blends.py -- /absolute/path/to/blender-source-v1
```

첫 명령은 이 폴더의 `blend/`, `renders/`, `reports/build.json`을 다시 만든다. 수정한 원본을 덮어쓰지 않도록 복사본에서 실행한다. 두 번째 명령은 검사 결과만 갱신한다.

## 렌더의 의미와 남은 과제

Cycles CPU 24샘플·디노이즈·512px·AgX Medium High Contrast로 렌더했다. 모델별 최대 치수를 기준으로 카메라를 맞춰 접촉 시트의 크기가 실제 월드 스케일과 다르다. CPU 렌더는 Blender에서의 재질·형태 확인이며 모바일 GPU나 Godot의 화면을 입증하지 않는다.

현재도 단순한 조형과 평면 색상 중심이다. 광석 파편의 표면 부착, 밧줄 교차 부위, 포션의 내용물 표현, 공통 모서리 마감, 게임 카메라에서의 식별성은 추가 미술 검토가 필요하다. UV/텍스처 세트·충돌체·Unity 패키지·실기기 성능·외부 사용자 평가도 미완료다. 데모 기능 확대보다 품질 개선을 우선한다.
