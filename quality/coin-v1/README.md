# Trailwood 코인 품질 개선 초안

2026-10-28. 검토용이며 기존 배포 모델은 교체하지 않는다.

앞면에만 있던 단순 막대를 양면 마름모 링 문양으로 변경하고, 16각 테두리에 경사면을 추가했다. 크기는 기존과 동일한 지름 0.36m 기준으로 비교했다. 실제 게임에서는 픽업/장식 용도에 맞게 축소해야 한다. 독자적 절차 생성 형상이며 외부 모델 입력은 없다.

- `currency_coin_quality.glb`: 192삼각형, 3재질, Y-up·미터, 정면 -Z, 바닥 중심 원점. 금속도 .65–.8, 거칠기 .35–.5.
- `currency_coin_quality.json`: 부품 단위 원본 데이터.
- `comparison.png`: 기존 100삼각형/개선 192삼각형, 동일 스케일·카메라·조명. 증가한 폴리곤 수 자체를 품질 증거로 삼지 않는다.
- `six_views.png`: 양면과 측면 확인용.
- `coin_64.png`, `coin_128.png`, `coin_256.png`: 작은 화면 검토용 이미지.
- `before.json`: 자체 제작한 이전 모델, 비교 재현용.

Python 3, NumPy, SciPy, Pillow 설치 후:

```
python build.py
python check.py
python render_review.py
```

검사 통과: 유한 좌표, 퇴화 삼각형 없음, 양면/문양 대칭, 앞뒤 캡 법선, 용접 좌표 기준 몸체의 폐쇄성과 에지 방향, GLB 헤더/재질/삼각형 수. 별도 Three.js GLTFLoader에서 로드, 3재질, 재질 값과 바닥 경계도 확인했다.

문양은 몸체와 분리된 돌출 링이며 전체를 단일 수밀 메시로 합치지 않았다. 링 바닥은 몸체에 0.2mm 묻어 떠 보이는 틈을 방지했다. 각 측면의 문양은 거의 보이지 않으므로 회전 픽업의 모든 각도에서 문양이 읽힌다는 주장은 하지 않는다.

간이 검토 렌더는 면 조명/깊이 버퍼를 사용하며 PBR 금속 반사를 재현하지 않는다. 앞뒤 명도 차이는 같은 고정 광원에 따른 결과다. 실제 게임 엔진에서 재질·반사 환경을 확인해야 한다.

미검증: Unity/Godot, 모바일 GPU 비용, glTF 공식 검증, 외부 식별성 평가, Blender 편집 원본. 판매 품질 승인 보류.
