# Trailwood 포션 품질 개선 초안

2026-10-28. 검토용이며 기존 배포 모델 미교체.

모바일 기본 제공안으로 모든 재질을 불투명하게 유지했다. 병 상단과 내용물 영역을 두 색으로 구분하고, 양면 물방울 표식과 목 묶음·마개를 추가했다. 붉은 부분은 내용물을 나타내는 스타일 표현이며 실제 유리, 투명 창 또는 별도의 액체 시뮬레이션이 아니다. 상업적으로 완성된 품질이라는 판정은 아직 하지 않는다.

- `consumable_health_potion_quality.glb`: 260삼각형, 4불투명 재질, Y-up·미터, 정면 -Z, 바닥 높이 0.
- JSON/Python: 부품 단위 원본 데이터와 생성기. 외부 모델 입력 없음.
- `comparison.png`: 기존 152삼각형/개선 260삼각형. 같은 카메라·월드 스케일·광원. 증가한 삼각형 수는 그 자체로 품질 증거가 아니다.
- `six_views.png`, `potion_64.png`, `potion_128.png`, `potion_256.png`: 형태·명도·작은 화면 검토용.
- `before.json`: 자체 제작한 이전 모델.

Python 3, NumPy, SciPy, Pillow 설치 후:

```
python build.py
python check.py
python render_review.py
```

검사 통과: 유한 좌표, 퇴화면 없음, 두 재질로 나뉜 병 몸체의 용접 좌표 기준 폐쇄성·에지 방향, 각 장식 부품의 폐쇄성·양의 체적, 양면 표식 대칭, GLB 헤더/4불투명 재질. 별도 Three.js GLTFLoader로 260삼각형, 4재질, 재질 값·바닥 높이와 경계를 확인했다.

간이 렌더는 면 조명과 깊이 버퍼를 사용하며 최종 엔진의 PBR/접지 그림자를 재현하지 않는다. 장식과 몸체는 별도 메시 부품이며 서로 의도적으로 겹친다. 표면 부착 상태의 극근접 검토, 사용자 식별성, Unity/Godot 가져오기, 모바일 GPU 측정, glTF 공식 검증, Blender 편집 원본은 미완료다. 판매 승인 보류.
