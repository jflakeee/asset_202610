# Trailwood 밧줄 품질 개선 초안

2026-10-28. 검토용이며 기존 배포 모델은 교체하지 않는다.

60개의 독립된 막대와 묶음 막대 구조를, 2.75회 감은 연속 코일과 별도 묶음 고리로 변경했다. 외부 모델 입력이 없는 자체 절차 생성 형상이다.

- 삼각형: 980 → 606, 약 38.2% 감소. 재질은 2개 유지. GPU 비용 감소를 실제 측정한 결과는 아니다.
- 코일: 경로 49샘플, 단면 5각. 인접 단면을 이어 내부 마감 면 없이 연결하고 자유 끝단 두 곳만 마감한다.
- 묶음: 12샘플 폐곡선. 실제 매듭의 교차 구조를 구현한 것은 아니며 묶음 표현용 고리다.
- `material_rope_quality.glb`: Y-up·미터, 정면 -Z, 바닥 높이 0. 미터 단위 크기는 소품 용도에 맞춰 조정한다.
- JSON/Python: 부품 단위 원본과 생성기. 별도 Blender 원본은 아직 없다.
- `comparison.png`: 같은 스케일/카메라/광원의 기존·개선 비교.
- `six_views.png`, `rope_64.png`, `rope_128.png`, `rope_256.png`: 방향별·작은 화면 검토.

Python 3, NumPy, SciPy, Pillow 설치 후:

```
python build.py
python check.py
python render_review.py
```

유한 좌표, 퇴화면 없음, 부품별 닫힌 에지 연결 및 방향, 양의 체적, 경로/끝단에 따른 면 수, 바닥 높이, GLB 헤더와 재질/삼각형 수 검사를 통과했다. 별도 Three.js GLTFLoader로 로드 및 재질·크기를 확인했다.

닫힌 에지 검사는 자기 관통이 없다는 증명이 아니다. 코일과 묶음 부품의 접촉/관통, 극근접에서 보이는 5각 단면, 실제 매듭 표현은 추가 검토가 필요하다. 간이 렌더는 면 조명과 깊이 버퍼를 사용하며 최종 엔진 음영을 재현하지 않는다.

Unity/Godot 가져오기, 모바일 GPU 성능, glTF 공식 검증, 외부 식별성 평가와 미술 승인은 미완료다. 판매 품질 승인 보류.
