# 원설계84종 LOD 후보·생략 검토표

2026-10-29. **AT12 구현 진전이며 최종 통과·판매 승인본이 아니다.**

84종 각각 LOD1/LOD2를 실제 원형 부품에서 검토해168개 판단 기록을 만들었다. 생성/실루엣 검사에 통과한 후보91개를 제공하며, 제약 안에서 삼각형이 줄지 않는77개 경우는 OMISSION_REVIEW_REQUIRED로 남겼다. 동일한 LOD0 파일을 복제해 LOD 개수로 세지 않는다. 모든 미술·생략 승인은 PENDING/false다.

## 생성과 검사

부품별 볼록성·축 경계 보존과 샘플 지지거리 제약으로 단순화한다. 비볼록 부품은 임의로 볼록체로 채우지 않고 유지한다. 원래 팔레트 슬롯은 최근접 원본 면으로 대응하며, 재질/텍스처·소켓 노드를 유지했다. 색상 면 분할과 확대 시 음영은 별도 미술 검토가 필요하다.

실제 내보낸 GLB를 읽어 공통 카메라 프레임으로 256px 정면/측면/45도/상면 실루엣을 비교했다. 각 방향 IoU가 LOD1은0.95, LOD2는0.88 이상이어야 한다. 목표 삼각형 비율50%/20%는 강제 합격 조건이 아니며 구조 보존을 우선한다.

첫 시도의 미달2개는 reports/first_attempt.json에 남겼다. 분기 가지와 직선 통나무의 지지거리 허용폭을 줄여 재생성한 결과, 최종 미달 후보는0개다. 한 경우는 더 이상 감소하지 않아 생략 검토로 이동했다. 실패를 승인된 예외로 바꾸지 않았다.

91개 파일 전부 Khronos glTF Validator2.0.0-dev.3.10 오류·경고0건. 파일 SHA-256과 판정 기록을 연결했다. check_catalog.py는84개 ID/168판정, 실제 감소, 4방향 점수, 파일 목록/해시와 공식 검사 범위 일치를 다시 확인한다.

## 아직 AT12가 완료가 아닌 이유

77개 생략안의 개별 승인, 엔진의 실제 LOD 전환과 콜라이더 불변 연결, GPU 실루엣/음영, 사람의 미술 검토가 남았다. 콜라이더는 기존 LOD0 것을 재사용하는 정책이며, 이번에는 엔진에서 그 연결을 검사하지 않았다. 자동 전환 거리도 제공하지 않는다. 소켓 유지와 단순화 후보 존재만으로 완성된 엔진 리소스라고 표시하지 않는다.

검토 ZIP에는 후보 models와 문서/코드/보고서만 포함한다. 원래84종 LOD0와 생성기들은 저장소의 재생성 절차로 준비한다. atlas/새 모델 유형/추가 테마로 모델 수를 부풀리지 않는다.

## 재현

저장소의 source-only 생성 산출물을 completion-work-v1/prepare_checkout.py 절차로 복원한 사본이 필요하다. Python NumPy/SciPy/Pillow와 기존 creation 모듈을 사용한다.

```
python build_catalog_lods.py /path/to/restored/repository
node validate.cjs /path/to/gltf-validator
python check_catalog.py
```

생성기는 이 폴더의 models와 보고서를 갱신하고 더 이상 참조하지 않는 생성 GLB를 제거한다. 수정 원본이 있는 폴더에서 실행하지 않는다. 공식 검사 패키지는 별도 테스트 의존성이며 런타임에 필요하지 않다. 판매 ZIP이나 승인 기록은 만들지 않는다.
