## 파일과 재현

`inputs/`는 자체 제작한 이전 검토본, `sources/`는 이번 부품별 메시 데이터, `models/`는 이번 GLB다. 외부 모델 입력 없음. Y-up·미터, 정면 -Z, 바닥 높이0. 모델별 실제 치수는 서로 다르며 최종 제공용 스케일 결정이 필요하다.

Python 3, NumPy, SciPy, Pillow 설치 후:

```
python build.py
python check.py
python review.py
```

`check-three.mjs`는 별도의 버전이 맞는 Three.js 테스트 런타임 폴더를 인자로 받는다. 해당 폴더는 `GLTFLoader.js`, `three.module.js`, 로더 의존 모듈과 bare `three` import를 해결하는 패키지 설정이 필요하다. 외부 의존 코드는 이 패키지에 재배포하지 않았다.

```
node check-three.mjs /absolute/path/to/three-test-runtime
```

이번 작업 환경에서 Python 검사와 Three.js 검사를 모두 실행했다. 유한 좌표·퇴화면 없음, 광석/밧줄 부품의 닫힌 에지 방향, 버퍼 범위·정렬, 정규화된 법선, 정점 색상 범위, 삼각형/재질/프리미티브 수, 바닥 높이, 상자 0/52.5/105도 포즈를 확인했다. 전체 자기 관통이나 공식 glTF 적합성을 증명하는 검사는 아니다.

## 남은 품질 문제

조형은 아직 단순한 기본형/평면 색상 중심이다. 광석 파편의 자연스러움, 밧줄 교차 부위, 포션 상단과 액체 표현, 공통 모서리 처리의 미술 검토가 남았다. 정점 색상을 지원하지 않는 커스텀 셰이더에서는 흰색으로 보일 수 있으므로 지원 엔진에서 반드시 확인한다. Unity/Godot 호환성을 시험 없이 보장하지 않는다.

목표 기기 성능, 외부 식별성 평가, 공식 glTF 검증, 편집 가능한 Blender 원본, 엔진 프리팹과 패키징도 미완료다. 데모 기능 확대보다 품질 검증을 우선한다.
