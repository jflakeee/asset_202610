# Trailwood 6종 FBX 제공본 — Blender 왕복 검토

2026-10-28. **편집/교환용 FBX 선택안이다. Unity에서 검증한 패키지가 아니며 판매 품질 승인 전이다.** 기존 GLB 배포본은 유지한다.

`../blender-source-v1/blend/`의 기본 원본에서 자산 메시와 Empty 계층만 선택해 FBX 7.4 Binary로 내보냈다. 카메라·조명·렌더 설정은 포함하지 않는다. 근접 화면용 모서리 마감 변형이 아닌 기본 조형이다.

## 검사 결과

Blender 4.5.9 LTS에서 내보낸 후 원본 장면을 초기화하고 FBX를 새로 가져왔다. 6종 모두 메시 수·삼각형 수 유지, 월드 경계 좌표 오차1mm 이내 검사를 통과했다. 단위/축은 FBX의 Y-up·-Z forward·미터 기준 설정으로 내보냈으며 재가져오기 경계로 크기 유지 여부를 검사했다.

|종류|메시 수|삼각형|FBX bytes|
|---|---:|---:|---:|
|상자|42|568|409,228|
|광석|4|42|24,636|
|코인|5|192|29,884|
|밧줄|3|682|38,284|
|포션|6|260|34,172|
|통나무|5|160|32,620|

상자 힌지 계층과 회전 애니메이션을 포함한다. Blender 30fps, 프레임1/10/19에서 시작 자세 대비 회전0°/52.5°/105°를 확인했다. FBX 재가져오기 검사에서 기본 시간 오프셋을 적용하면 한 프레임 밀렸으므로 검사기는 `anim_offset=0`을 명시한다. 타 엔진에서는 클립 시작/끝과 재생 시간을 별도로 확인한다.

재질 수와 Principled의 기본색·금속도·거칠기 값도 Blender 왕복 전후 비교했다. 해당 파라미터의 측정 최대 오차는6종 모두0이었다. 이것이 Unity/Unreal 셰이더나 최종 화면의 동일성을 보장하지는 않는다.

## 용도와 제한

합계568,824bytes로 압축 GLB6종 합계148,328bytes보다 약3.8배 크다. FBX 상자는 샘플링한 변환 애니메이션과 부품 계층을 포함한다. 모바일 기본 런타임 제공본은 `../core6-r3/`를 유지하고, FBX는 이를 필요로 하는 제작 파이프라인에서 선택한다.

FBX는 부품별 색상 재질을 사용하므로 공유 프로필/정점 색상으로 묶은 GLB와 재질 수 및 렌더 부품 구성이 다르다. 외부 텍스처나 메시를 추가하지 않았다. 충돌체·엔진 프리팹·Unity .meta 파일은 포함하지 않는다. Unity/Unreal 실제 가져오기, 축/피벗 표시, 애니메이션 클립 설정, GPU 화면/성능은 미검증이다.

## 재현

이 폴더와 `../blender-source-v1/`의 원본을 내려받고 복사본에서 실행한다. 기존 FBX와 reports/roundtrip.json을 덮어쓴다.

```
blender --background --python-exit-code 1 --python build_check.py -- /absolute/path/to/fbx-review-v1 /absolute/path/to/blender-source-v1
```

실패하면 Blender가 종료 코드1을 반환하도록 `--python-exit-code 1`을 지정한다. `reports/roundtrip.json`의 passed=true와6개 모델 결과를 함께 확인한다. 전체 자기 관통·토폴로지 편집성·플랫폼별 호환성을 검사하는 도구는 아니다.
