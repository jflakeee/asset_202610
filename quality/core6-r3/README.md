# Trailwood 6종 — 용량 개선 및 공식 glTF 검사본

2026-10-28. **미술 2차 검토본의 조형을 유지한 기술 개선본이며 판매 승인 전이다. 기존 사이트 모델 미교체.**

## 결과

|모델|이전 GLB(bytes)|이번 GLB(bytes)|삼각형|
|---|---:|---:|---:|
|상자|67,420|40,976|568|
|광석|6,856|6,180|42|
|코인|22,068|11,600|192|
|밧줄|75,016|61,668|682|
|포션|30,316|18,268|260|
|통나무|18,636|9,636|160|
|합계|220,312|148,328|1,904|

합계 약 **32.7% 감소**. 이전 검토본의 13개 렌더 프리미티브와 재질 프로필을 유지한다. 실제 GPU 시간·드로콜·실기기 메모리는 측정하지 않았다.

- 정점 색상: FLOAT RGB → normalized UNSIGNED_BYTE RGBA. 선형 색상 공간 유지. 색상은 무손실이 아니며 채널당 반올림 오차 허용값은 0.5/255다. 측정 최대 선형 색상 오차는 약0.001944.
- 정점 인덱싱: float32 위치·법선·양자화 색상이 모두 같은 정점만 공유한다. 모서리의 서로 다른 법선은 합치지 않는다.
- 삼각형을 다시 펼쳐 비교한 위치/법선, 노드 계층, PBR 재질, 상자 시간/회전 키 데이터는 이전 GLB와 동일하다.
- 정점 수 5,712 → 4,320. 밧줄은 면 법선을 유지하므로 합칠 수 있는 정점이 적다.

## 공식 검사

KhronosGroup 공식 `gltf-validator` npm 패키지 **2.0.0-dev.3.10**을 실행했다. `validation/`에 수정하지 않은 모델별 JSON 결과와 요약을 저장했다.

6종 모두 errors=0, warnings=0, infos=0, hints=0. 문제 무시 목록과 심각도 변경을 사용하지 않았다. 이 결과는 해당 버전 검증기의 형식/데이터 검사를 통과했다는 뜻이며, 미술 품질이나 모든 엔진/기기 호환성 보장이 아니다.

출처: https://github.com/KhronosGroup/glTF-Validator
색상 인코딩 기준: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html

## 재현

`../core6-r2/`의 부품 원본과 기존 GLB를 입력으로 사용한다. 독립된 새 조형이나 외부 모델 입력을 추가하지 않았다. 저장소 구조 그대로 내려받아야 기본 경로가 맞는다.

Python 3, NumPy 설치 후:

```
python build.py
python check.py
```

다른 위치의 원본은 두 명령에 `--source /path/to/core6-r2`를 추가한다.

공식 검사 도구는 개발 검사용이며 제공 모델의 런타임 의존성이 아니다. 이 폴더에서:

```
npm install --no-save --package-lock=false --ignore-scripts gltf-validator@2.0.0-dev.3.10
node validate.cjs
```

`check-three.mjs`에는 버전이 맞는 Three.js 테스트 런타임 폴더를 인자로 전달한다. GLTFLoader.js, three.module.js와 로더 의존 모듈/bare import 설정이 필요하다. 작업 환경에서 6종 로드·인덱스 삼각형 수·정규화 색상 표시·바닥 경계 및 상자 0/52.5/105도 자세를 확인했다.

```
node check-three.mjs /absolute/path/to/three-test-runtime
```

## 남은 출시 조건

현재 조형은 여전히 단순한 기본형/평면 색상 중심이며, 유료 판매 가치가 입증됐다고 판단하지 않는다. Unity/Godot 실제 가져오기, 목표 모바일 기기 성능, 사용자 식별성/선호 평가, 미술 마감, Blender 편집 원본 및 엔진 패키징이 남아 있다. 정점 색상을 읽지 않는 커스텀 셰이더에서는 별도 설정이 필요하다.
