아이템을 획득하고, 회복약과 보물상자를 사용해 보세요.

아래 아이템을 누르면 인벤토리에 추가됩니다.

자동전투 · 접근 획득

파란 원이 플레이어입니다. 화면을 누른 채 이동 방향으로 드래그하세요. PC에서는 전투 화면 클릭 후 방향키 또는 WASD로 이동합니다.

붉은 적은 가까워지면 추적합니다. 접촉 시 체력 −8, 피격 후 1초 동안 추가 피해를 받지 않습니다. 회복약을 먼저 획득한 뒤 전투를 시작하세요.

보물상자 제작

시험 제작법: 통나무 2 + 철광석 1 + 밧줄 1 → 상자 1

2D 아이콘 기반 기능 예제입니다. 2D 이동·적 추적·자동 공격·접촉 피해를 지원합니다. 3D 월드·상자 모델 애니메이션·효과음·저장은 포함하지 않습니다. 새로고침하면 초기화됩니다.
