데이터를 불러오는 중입니다.

재료 수집 · 자동전투

왼쪽 통나무 → 왼쪽 아래 철광석 → 아래쪽 밧줄에 접근하세요. 세 묶음을 모으면 아래에서 보물상자 1개를 제작할 수 있습니다.

파란 원이 플레이어입니다. 화면을 누른 채 이동 방향으로 드래그하세요. PC에서는 전투 화면 클릭 후 방향키 또는 WASD로 이동합니다.

붉은 적은 가까워지면 추적합니다. 접촉 시 체력 −8, 피격 후 1초 동안 추가 피해를 받지 않습니다. 회복약을 먼저 획득한 뒤 전투를 시작하세요. 다른 탭이나 창으로 이동하면 전투가 일시정지됩니다. 돌아온 뒤 전투 재개를 누르세요. 바닥 재료는 한 번씩만 획득되며 처음부터 버튼으로 복원됩니다.

보물상자 제작

아이템별 3D 미리보기와 2D 전투 기능 예제입니다. 2D 이동·적 추적·자동 공격·접촉 피해를 지원합니다. 합성 효과음은 소리 켜기로 활성화합니다. 상자 보상은 2D 아이콘 연출로 표시합니다. 3D 월드·상자 뚜껑 애니메이션·저장은 포함하지 않습니다. 새로고침하면 초기화됩니다.
