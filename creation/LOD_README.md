# Trailwood LOD1 검토 패키지 — v0.17 갱신

원본 자체 제작 바위·나무 4종의 LOD1 GLB를 추가했다.
이전 통합 데모, 개별 모델, 배치 및 충돌체 명세를 함께 포함한다.
현재 통합 데모는 화면 높이 기반 LOD 전환과 히스테리시스를 제공한다.
아래 기하 검사는 실제 GPU 전환 화면 품질을 대신하지 않는다.

| 모델 | LOD0 | LOD1 | 감소율 | 표본 방향 외곽 변화 / 최대 크기 |
|---|---:|---:|---:|---:|
| 낮은 바위 | 66 | 52 | 21.2% | 1.81% |
| 세로 바위 | 70 | 48 | 31.4% | 1.69% |
| 둥근 나무 | 352 | 244 | 30.7% | 1.99% |
| 침엽수형 나무 | 248 | 184 | 25.8% | 0.99% |

삼각형 상한 초안(40/44/180/128)보다 외곽 유지에 우선순위를 두었다.
4종 모두 당초 삼각형 상한을 넘긴 검토 후보이며 출시 확정본은 아니다.
높이·폭·깊이, 각 부품의 축별 극점, 원점은 유지한다.
나무 수관의 덩어리와 층수, 가지 부품 수는 유지한다.
울타리는 이미 44~56 triangles이므로 이번 LOD 제작에서 제외했다.

## 측정의 의미

원본 부품 정점에서 방향별 최대 내적을 구하고 축소 후 값과 비교한다.
구면 방향 1024개와 축 방향 6개, 총 1030방향을 표본으로 사용했다.
각 부품 오차의 최댓값을 모델 최대 크기로 나눈 값이 표의 마지막 열이다.
이 값은 표본 방향의 support-function 오차이며 모든 표면의 최대 거리나
모든 시점에서 실루엣 오차 2% 이하를 보장하는 Hausdorff 검증이 아니다.
부품별 convex hull을 사용하므로 휜 줄기의 오목한 영역이 채워질 수 있다.
팔레트 색은 새로운 면 방향에 따라 재할당되어 색 경계도 바뀔 수 있다.
따라서 근거리/원거리 전환 시 팝핑과 줄기 형태를 엔진에서 확인해야 한다.

## 파일

- lod_output/models: LOD1 모델 4개.
- lod_output/lod0: 비교용 원본 4개.
- lod_output/source_meshes: Z-up 미터 좌표의 축소 메시.
- lod_output/validation.json: 부품별 외곽 표본 오차, 목표 달성 여부.
- lod_output/*.khronos.json: 공식 GLB 검사 결과.
- lod_output/preview.png: 실제 내보낸 모델의 같은 시점 비교.
- demo_output: 이전 통합 데모·충돌체 JSON·배치 정보.

GLB는 Y-up, 원본 JSON은 Z-up이며 변환은 (x,z,-y)다.
파일명과 실제 노드명 모두 LOD1으로 지정했다. 엔진 자동 전환을 뜻하지는 않는다.
충돌체는 LOD0 기준으로 고정하고 시각 메시만 교체하는 설계다.
전환 초안: 화면 높이 80px 미만 LOD1, 100px 초과 LOD0 복귀.
현재 화면 크기 계산·히스테리시스는 구현되어 있다. 크로스페이드는 제공하지 않는다.

## v0.17 실루엣 회귀 개선

기존 침엽수형 LOD1(138 triangles)은 256px 직교 실루엣 IoU 검사에서
정면 0.9452·측면 0.9403으로 설계 기준 0.95에 미달했다.
이 모델만 부품 외곽 표본 오차 허용값을 최대 크기의 2%에서 1%로 줄였다.
결과는 184 triangles로, LOD0 대비 25.8% 감소를 유지한다.
다른 3개 LOD1과 모든 LOD0의 파일은 변경하지 않았다.

`verify_lod_iou.py`의 수정하지 않은 기준으로 4모델×4시점이 모두 통과했다.
모델별 최소 IoU: 낮은 바위 0.9907, 세로 바위 0.9687,
둥근 나무 0.9681, 침엽수형 나무 0.9860.
정면·측면·45도·윗면을 동일한 투영 프레임에서 비교하고,
이동시킨 메시가 실패하는 음성 대조 검사도 통과했다.
근거는 `lod_iou_output/report.json`과 실루엣 비교 PNG다.
LOD2·다른 모델의 LOD 정책·GPU 팝핑 검증·아트 승인은 남아 있다.

## 재현 및 검증

의존성: Python, numpy, scipy, pillow, matplotlib.
패키지 루트에서 `python build_lods.py` 실행.
GLB 검사는 별도 gltf-validator 설치 후
`NODE_PATH=/path/to/node_modules node validate_khronos.cjs lod_output` 실행.
원본 source_meshes와 GLB 입력 파일, 공유 생성기 소스를 함께 제공한다.
개별 부품의 닫힌 topology, Euler=2, 양의 체적, 축별 경계 보존과
내보낸 GLB의 정점/인덱스 재읽기를 검사했다. 공식 검사 오류·경고 0건.
엔진 임포트, 물리 시뮬레이션, 실제 프레임 성능 및 아트 승인은 미완료다.
